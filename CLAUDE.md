## Architecture

Single-page personal portfolio (React 18 + TypeScript + Vite 6 + Tailwind CSS 3), deployed on Vercel. All content is hardcoded in component files — there is no CMS, router, or data fetching layer.

**Structure**: `App.tsx` renders `<Navbar />` followed by one section component per `<section id="...">`. Each section is a self-contained file under `src/components/` with its own data, styling, and scroll-target anchor. Smooth-scroll navigation connects the navbar links to section IDs.

**Design system — neo-brutalist**: Thick black borders (`border-[3px] border-black`), heavy offset shadows (`shadow-[4px_4px_0px_0px_rgba(0,0,0,1)]`), and bold highlight spans (`bg-[#COLOR] text-white px-3 py-1 inline-block`). Recurring color palette:

| Color | Hex | Usage |
|---|---|---|
| Blue | `#2F81F7` | Primary accent, highlights |
| Coral/Red | `#FF6B7A` / `#FF6B6B` | Secondary accent, hero |
| Gold | `#FDB927` | Tertiary accent, badges, metrics backgrounds |
| Indigo | `#6366F1` | Skill bars, icons, internship header |
| Near-black | `#0B0B0B` | Text, buttons, dark sections |
| White | `#FFFFFF` | Page background |

Fonts: `Onest` (Latin) + `Noto Sans SC` (Chinese), loaded from Google Fonts in `index.html` and configured in `tailwind.config.js`.

**Key patterns**:
- Navigation uses `scrollIntoView({ behavior: 'smooth' })` for all internal links; no React Router.
- The skills section uses a CSS `@keyframes marquee` animation (defined in `index.css`) for an infinite-scroll tag cloud.
- Internship and project cards follow a consistent card pattern: rounded corners, black border, metric grids with `bg-[#FDB927]/10`, and tag pills.
- Mobile responsive: navbar collapses to a floating hamburger button; most grid layouts stack to single column.

## Reference template

`paperfolio-portfolio-template/` is a Next.js template used as design reference. It is gitignored and not part of the active project. The current project was rebuilt from it using Vite + React.

## Deployment

Deployed via Vercel. The `.env.local` file (gitignored) contains a Vercel OIDC token auto-generated by the Vercel CLI — do not commit it.
